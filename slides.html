概念

AI 使用的五個層次

今天直接帶你走到 Lv.4——你要學的不是某一個工具，是「怎麼把 AI 編進備課流程」

層級做法代表工具
Lv.1問答機 — prompt → copy → pasteChatGPT 網頁版
Lv.2整合工作流 — 串接各種 AI 服務NotebookLM + Napkin + Claude
Lv.3初級助理 — AI 規劃步驟、操作電腦Claude Code、Gemini CLI
Lv.4進階助理 — 你訂規則、AI 一直照做Claude Skill、n8n
Lv.5專屬助理 — AI 規劃步驟＋操作電腦OpenClaw、Hermes
方法

逆向設計（Backward Design）

Wiggins & McTighe，Understanding by Design（1998）

先決定「學生上完這堂課要會什麼」，再倒推每一步：

學生最終要會的事 = 做完一份學習單（Step 3）
要產出學習單 → 前面要有 研究筆記
要有完整教案 → 前面要 先有學習單（教案的目標就是讓學生做完這份）
要有教案的視覺輔助 → 前面要有 兩張圖

從終點往回排——AI 不是替你決定要去哪，是你決定了之後，AI 替你跑完路線。

STEP 1

NotebookLM——讀懂課文＋產出研究筆記

操作
  1. 上傳 5 個橋頭糖廠素材（網址或 PDF）
  2. 依序問 4 個問題：大方向 → 細節 → 文宣 vs 史料 → 教學切入
  3. 要求打包成「研究筆記」（含參考文獻、Napkin 用條列）
老師人工檢視
  • 讀一遍，刪掉錯的
  • 核對出處編號（NotebookLM 會錯亂）
  • 砍掉重複（順便省 token）
  • 補旁註（教學判斷）
這一步是整套流程中老師價值最高的環節。 AI 給的是「資料整合」，不是「教學判斷」——後者只有老師會。
研習現場示範時，刻意慢下來做這一步——讓老師看到「AI 不會替你做的判斷」具體長什麼樣

從研究筆記第七節複製貼上——NotebookLM 已經幫你寫好兩段條列

STEP 4 — 壓軸

Claude——倒推設計教案

UbD Stage 3：以「能完成學習單」為目標倒推教學流程

上傳四個檔案
研究筆記 + 兩張 PNG + 學習單 + 教案範本（兒時記趣）

Claude 同時做四件事：

✓ 讀學習單，反推學生要會什麼
✓ 抽範本格式結構
✓ 設計教學流程，每段對應到學習單
✓ 把兩張 PNG 直接嵌進 docx
「我按下送出，下次再碰電腦的時候，已經是下載完成的教案 .docx 了。」 —— 這就是 Lv.3 + UbD 的真貌
風險與備案

如果撞牆怎麼辦？

出現 "Get Pro" 或 "This response didn't load" 時，由輕到重四層 fallback：

1
切換到 Haiku 4.5
同帳號、同對話、最常奏效（成本是 Sonnet 的 1/3-1/5）
2
關掉舊對話、開新對話
避免繼承過長對話歷史，input token 從 0 累積
3
退到 Gemini
免費 Gemini 2.5 Pro 容量更寬，prompt 完全相容
4
退到複製貼上
把素材貼進對話框，比 fetch 省 token

切換順序的精神：盡量留在原工具——切 Haiku 比換對話順、換對話比換工具順。

PART #2

模型、代理人與你

SECTION 1 — Lv.4

Prompt 是封信，Skill 是 SOP

PROMPT
  • 寫一封信，寄完就丟
  • 每次重新打
  • 你給 AI 一個任務

例：「請為橋頭糖廠寫教案」

SKILL
  • 訂一個 SOP，永遠跟著用
  • 寫一次，AI 一直照做
  • 你給 AI 一份「流程說明書」

例：「請用閱讀教案流程處理 X」

下次打開 Claude，你只要說一句：
「請用閱讀教案流程，為『左營眷村文化』產出國中跨領域閱讀教案。」
→ 上傳素材 → 學習單＋教案兩份 docx 連續產出。這就是 Lv.4。

SECTION 2 — Lv.3

把 AI 從瀏覽器拉出來

PART #1 跟 Section 1 的所有動作都還關在「網頁」裡——Lv.3 是把玻璃罩拿掉

# 一句中文 prompt：
桌面這堆檔案太亂了。請幫我：
1. 看一下有哪些檔案，按主題分類
2. 為每一類建一個子資料夾、把檔案移進去
3. 給每個資料夾用 macOS Finder 標籤上不同顏色

90 秒後，桌面乾淨。

重點不是整理桌面這件事——是「AI 出了瀏覽器、進入你的檔案系統」這個門檻。

SECTION 3 — 模型

AI 怎麼辦到的（30 秒講完）

AI 不是查資料庫、不是「知道事實」。
它的本質是 猜下一個字。

函數視角：輸入文字 → 模型計算 → 輸出最可能的下一段文字。沒有「記憶」。
Token 視角：模型把文字切成「token」處理。中文一字約 1.5–2 token。
幻覺的本質：模型在「猜」、不在「記」——寫得很像那回事的東西可能整個不存在。

→ 凡有標準答案的學科，AI 產出 必須 老師最後把關。

SECTION 3 — 模型

怎麼選模型？

以 Anthropic Claude 為例（其他家邏輯類似）

模型用在額度成本
Opus 4.7 複雜分析、深度思考 高（5x Sonnet）
Sonnet 4.6 嚴格照範本、多附件整合 中（基準）
Haiku 4.5 單純任務、快速產出 低（1/3 Sonnet）
對應今天的流程
  • Step 4 教案（要照範本）→ Sonnet 4.6
  • Step 3 學習單（單純）→ Haiku 4.5
  • 回家備課 → Haiku 為主，複雜時切 Sonnet
SECTION 3 — 你

什麼東西不該丟雲端？

學生作文・輔導紀錄・IEP・未公開競賽作品

「這段如果被截圖貼到網路上，
我會崩潰嗎？」

會 → 別丟雲端。

進階解法（點到為止）：本機 AI（Ollama + Llama / Gemma 等開源模型）跑在你筆電上，資料完全不外流。
